Network Viewer Standalone 1.0.1

사용
- 화면 왼쪽 아래 아이템 / 유체 / 전력 버튼을 각각 누릅니다.
- On Mouse: 마우스를 올린 건물에서 연결을 추적합니다.
- ALL: 해당 종류의 전체 연결을 표시합니다.
- None: 해당 종류의 표시를 끕니다.
- F7: 전체 표시 켜기/끄기. 종류별 모드 선택은 다음 실행에도 유지됩니다.
- 필터 출력 화살표의 자원 아이콘: 해당 자원. ≠ 표시: 그 외 자원.
- 전력 점선: 노드 링크. 실선: 인접 건물의 실제 전력 연결.
- 연결하지 않은 다리도 인식되며 링크 상태가 표시됩니다.

독립 실행
이 ZIP에는 JavaScript 분석기와 표시 코드가 들어 있습니다.

해석 범위
- 아이템/유체 선은 구조적으로 가능한 경로입니다. 실제 초당 유량이나 생산 유지 보장이 아닙니다.
- 필터·포화·수신 공간·전력·압력 등 조건이 붙는 경로는 조건부로 표시됩니다.
- 공장의 입력/출력은 별도로 처리하며 공장 내부를 통과하는 벨트로 연결하지 않습니다.
- 현재 플레이어 팀의 건물만 분석합니다. 아직 배치되지 않은 설계도 미리보기는 분석하지 않습니다.
- v160.7 기본 운송 블록의 기존 규칙을 이식했습니다. 임의의 콘텐츠 모드가 추가한 특수 동작은 보장하지 않습니다.
- ALL은 화면 밖 선을 생략하고 10,000개 선분/100개 필터 배지 표시 한도를 둡니다.
  아주 큰 구조는 초기 분석이나 변경 직후 지연될 수 있습니다. 대형 설계도는 On Mouse를 권합니다.

1.0.1 필터 표시 수정
- 자원 아이콘을 화살표의 중앙에 겹쳐 표시합니다. 옆으로 퍼지지 않습니다.
- 입력선 또는 공급원에 마우스를 올리면 그 경로로 필터에 들어가는 방향의 배지만 표시합니다.
- 전체 연결(ALL)을 켰더라도 필터 아이콘은 마우스로 선택한 경로를 기준으로 표시합니다.
- 필터 자체에 마우스를 올리면 입력선을 가리키라는 안내를 표시합니다.
- 출력 쪽에서 추적해 입력 방향을 하나로 정할 수 없고 같은 화살표에 상반된 아이콘이 생기면 그 배지는 생략합니다.
- 재고를 측정해 흐름을 확정하는 기능은 아니며, 선택 경로의 구조적 진입 방향을 기준으로 합니다.
